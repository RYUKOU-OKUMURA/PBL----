### Phase 1 ― 入口の修復（最小工数・最大効果）【完了 2026-08-12】

**問題:** トップページの description が18字で、腰痛・肩こりの検索者を説明文で追い返している。

**採用した方式: (c) TCDテーマの metaタグ欄に直接設定。**

当初案の (a)折衷（キャッチフレーズを40字に圧縮）と (b)本格（Rank Math 有効化）は**両方とも破棄**した。Phase 0-2 で TCDテーマに title/description の独立欄が見つかり、「キャッチフレーズ1つを共用しているので長く書けない」という**制約そのものが存在しなかった**ため。

設定場所: `TCDテーマ → SEO → metaタグ → トップページ`

**影響範囲: トップページのみ。** 一般設定のキャッチフレーズにも、記事229本にも、Rank Math にも一切触れていない。

#### 実際に設定した値

**title（32字）:**
```
星ヶ丘 徒歩2分の整体院｜腰痛・肩こり・脊柱側弯症｜レッドコード
```
実測で順位のあるローカルクエリ（星ヶ丘 腰痛 9.3位／肩こり 13.6位／整体 8.3位）を**冒頭に配置**。「レッドコード」は指名検索の受け皿として末尾に残した。「日本で唯一の」は**入れていない**（§8 論点2 が未決着のため、ここに入れずに判断を先送りできる形にした）。

**description（89字）:**
```
名古屋市名東区・星ヶ丘駅から徒歩2分の整体院です。腰痛・肩こり・脊柱側弯症のご相談に対応しています。レッドコード（吊り下げ式の器具）を使い、根本原因施術に本気で取り組んでいます。
```

#### 修復前後

| 語 | Before（18字） | After（89字） |
|---|---|---|
| 腰痛 | ❌ 不在 | ✅ title・description |
| 肩こり | ❌ 不在 | ✅ title・description |
| 整体 | ❌ 不在 | ✅ title |
| 名古屋 | ❌ 不在 | ✅ description |

#### ゲート1: 通過（2026-08-12）

LiteSpeed Cache purge 後、`curl` で配信HTMLを実測。`x-cache: BYPASS`（キャッシュ未経由の生成HTML）を確認したうえで:

- `<title>` = 設定値と一致（32字）
- `<meta name="description">` = 設定値と一致（89字）
- `og:title` / `og:description` も同一値で同期
- 断定・保証表現の混入なし（`100%` の検出は CSS の `font-size:100%` 等で、メタ側はクリーン）

#### 検討の過程で1点、表現を差し替えた

description 初稿の末尾は「**再発しない**根本施術に本気で取り組んでいます」だった。「再発しない」は施術の属性として結果を保証する表現で、景品表示法の優良誤認（合理的根拠を示せない効果の断定）に触れうる。

「"取り組んでいます"に係る文脈だから問題ないのでは」という論点が出たが、景表法の優良誤認は**一般消費者が表示全体から受ける印象**で判定されるため、係り受けの構造では解消しない。「〜に取り組んでいます」は緩和にはなるがゼロにはならない。

→ 最終的に「**根本原因施術**に本気で取り組んでいます」に差し替え。**結果の保証ではなく、やっていることの記述**になったため印象判定でも問題なし。

**なお、当初あわせて指摘した「根本施術」の柔道整復師法第24条リスクは撤回した。** 24条が縛るのは柔道整復の業としての施術所の広告であり、当院は「整体院」として掲げ保険適用・接骨院を名乗っていないため、直接適用は無理がある。

**この件の教訓:** テーマオプションの meta 欄は `format_wp_drafts.py` の固定要素パイプラインも3種QAも通らない。**サイトで最も露出の高い96字が、QAの死角にある。** 今後ここを触る際は手動で薬機法・景表法チェックを行う。

#### 未着手のまま残した項目

- 現行の「**日本で唯一の**レッドコード整体院」は `og:site_name` と記事229本のtitle末尾に残存。景表法上の合理的根拠が必要になりうるが、**ブランド判断なので本人決裁事項**（§8 論点2）
- 「脊柱側弯症専門」は description に残した。側弯症は実際の稼ぎ頭なので**捨てず、腰痛・肩こりを足す**方針どおり
- 同画面の `ブログアーカイブページ` の meta 欄は**意図的に未設定のまま**。トップページ単独の効果測定を汚さないため、9/9 の判定後に着手する

### Phase 4 ― 執筆方針の転換

**原則:「症状名」ではなく「その人のセリフ」で書く。**

| 書かない | 書く |
|---|---|
| 「側弯症とは」（用語解説） | 「側弯症で立ちっぱなしがしんどい人へ」 |
| 「ミルウォーキー装具の種類」 | 「装具をすすめられて迷っている親御さんへ」 |
| 装具名・療法名を主クエリにする | 当事者が実際に打ち込む長い言葉を主クエリにする |

**優先クラスタ（実測で当事者クエリが確認できている領域）:**
1. 側弯症の**術後**クラスタ（976が実証済み・最大の稼ぎ頭）
2. ローカル受け皿ページ（星ヶ丘 腰痛／星ヶ丘 肩こり）— **現状ブログ側にゼロ**

**注意:** ネタ帳（`HPブログ記事/ネタ帳_検索クエリ由来.md`）の優先度Aは概ねこの方針と整合しているが、**用語型クエリが混ざっていないか**を今回の知見で再点検する。

### Phase 5 ― 範囲外だが最重要

**Googleビジネスプロフィール（マップパック）の最適化。**

ローカルクエリはSERP上部をマップパックが占有するため（**推測**）、その下の青リンク8〜13位は実質不可視。**投資対効果はブログ改修を上回る可能性が高い。**

ただし正直な規模感として、星ヶ丘系4クエリの合計は月108表示。全部1位でも月30〜40クリック。**この規模ではSEOは集客の主エンジンにならない。** それでも装具の726表示より星ヶ丘の108表示のほうが事業価値は上——**通える距離の人が、いま困っている検索**だから。
