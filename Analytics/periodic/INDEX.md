# periodic 一覧

正データは各フォルダの CSV。ビューは Cursor Canvas。HTML は任意。

比較するときは **正系列** だけを並べる。長さの違う窓を前期比に使わない。

GSC のサイト全体クリックは `gsc_site.csv`（2026-08 以降の新規取得）を正とする。記事CSVの `gsc_clicks` はクエリ×ページ API のため過少になる。

## 取得コマンド

```bash
# 直近の完了済み半月（1–14 または 15–末日）
bash Analytics/scripts/run_periodic.sh

# 進行中の半月を上書き更新
bash Analytics/scripts/run_periodic.sh --current

# 例外の14日（ad-hoc へ）
bash Analytics/scripts/run_periodic.sh --ad-hoc
```
