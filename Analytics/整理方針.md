# Analytics フォルダ整理方針

**作成日:** 2026-05-21  
**目的:** 分析データの保管・参照を整理する。定期取得は CSV を正とし、可視化は Cursor Canvas を主とする。

---

## 1. 基本方針

| 原則 | 内容 |
|------|------|
| **正（ソース）** | CSV（再取得・再分析可能な生データ） |
| **ビュー（表示）** | Cursor Canvas（分析時の主手段） |
| **ビュー（任意）** | HTML（`generate_report_html.py` でオンデマンド生成。手書きしない） |
| **要約（任意）** | `summary.md`（Cursor 等で書く読み物） |
| **用途で分ける** | 定期取得 `periodic/` と特派分析 `projects/` を混在させない |
| **ルート直下** | README・方針・横断 index のみ。CSV / スクリプトは置かない |

## 3. 命名ルール

### periodic（定期）

- **フォルダ名:** `YYYY-MM-DD_YYYY-MM-DD`（集計開始日_終了日）
- **正系列:** カレンダー半月。`1–14日` または `15–その月の末日`
- **例:** `2026-08-01_2026-08-14` / `2026-08-15_2026-08-31`
- 転がし「今日から14日」は `ad-hoc/` のみ。periodic 直下に増やさない
- 進行中の半月は同じフォルダを上書き（`--current`）

### projects（特派）

- **フォルダ名:** `YYYY-MM_テーマ`（英小文字・ハイフン）
- **例:** `2026-03_tv-redcode` / `2026-03_search-barrier`

### ファイル名（periodic 内）

| ファイル | 役割 |
|----------|------|
| `ga4_wp_gsc_analysis.csv` | 記事別 PV・セッション・GSC（クエリ×ページ由来） |
| `ga4_wp_gsc_analysis_queries.csv` | クエリ×ページ |
| `gsc_site.csv` | サイト全体の検索クリック・表示。判断の正 |
| `gsc_pages.csv` | ページ単位GSC（トップページを含む） |
| `meta.json` | 窓の役割と実際の取得終了日 |
| `index.html` | 自動生成レポート（任意） |
| `summary.md` | 任意。AI / 人間が書く解説 |

## 5. HTML 自動生成（やる方向・仕様）

### 5.1 方針

- HTML は **手書きしない**。`generate_report_html.py` が CSV を読んで出力する。
- 外部 CDN 可（Chart.js 等）。**単一 HTML ファイル**でブラウザ打开可能にする。
- データの正は CSV。HTML は再生成可能なビュー。

### 5.2 生成タイミング

1. **定期取得（デフォルト）**  
   `run_periodic.sh` / `analyze_content_seo.py` は **CSV のみ** 出力。HTML は生成しない。
2. **HTML（任意）**  
   `--html` フラグ、または `generate_report_html.py` を手動実行したときのみ生成。
3. **横断ダッシュボード**  
   `generate_report_html.py --index` 実行時に `Analytics/index.html` を更新。

### 5.3 期間レポート `index.html` の内容（Phase 1）

**ヘッダー**

- サイト名・集計期間・生成日時

**サマリーカード**

- 合計 PV / セッション / エンゲージドセッション
- GSC クリック / インプレッション / CTR
- （取得できる場合）前期比 % ※GA4 日次 API を別途呼ぶ or 手入力はしない

**表**

- 記事 TOP10（タイトル・PV・セッション・GSC クリック）
- 検索クエリ TOP10（クリック・インプレッション・平均順位）

**グラフ（Chart.js）**

- 日次セッション折れ線 … `ga4_traffic_trend_analysis.py` と連携、または GA4 API を HTML 生成時に取得

**フッター**

- データソース明記（GA4 / GSC / WordPress）
- 同フォルダ CSV への相対リンク

### 5.4 横断ダッシュボード `Analytics/index.html`（Phase 2）

- `periodic/` 一覧（期間・主要 KPI）
- 直近 3〜6 期間のセッション推移グラフ
- 各期間 `index.html` へのリンク

### 5.5 projects 向け HTML

- 既存 md（`README_analysis.md` 等）は **Phase 1 では移動のみ**。
- 必要なら Phase 3 で TV 分析などを `index.html` 化（優先度低）。

## 6. 運用フロー（整理後）

### 定期取得（2週間ごと）

```bash
# 直近の完了済みカレンダー半月
bash Analytics/scripts/run_periodic.sh

# 進行中の半月を上書き
bash Analytics/scripts/run_periodic.sh --current

bash Analytics/scripts/run_periodic.sh --dry-run
```

手動で期間を指定する場合:

```bash
START=2026-05-08
END=2026-05-21
python analyze_content_seo.py --start "$START" --end "$END"
```

数値の確認・解説は Cursor で CSV を渡して Canvas 表示する。

### HTML 生成（任意）

```bash
# 横断ダッシュボード（動向分析付き）
python Analytics/scripts/generate_report_html.py --index

# projects HTML 化
python Analytics/scripts/generate_report_html.py --all-projects
```

### トラフィック推移だけ見たいとき

```bash
python Analytics/scripts/ga4_traffic_trend_analysis.py
```
