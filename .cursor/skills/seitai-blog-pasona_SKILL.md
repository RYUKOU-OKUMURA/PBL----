# 整体院ブログ記事執筆スキル（PASONA版）

整体院・治療院のHPブログ記事を、一貫した品質で執筆するためのガイド。

## 文体・トーン

### 基本ルール
- **一人称**: 「僕」
- **敬体**: です・ます調
- **語りかけ**: 「〜なんです」「〜ですよね」など自然に
- **トーン**: 専門性 × やさしさ × 励まし
- **検索語の置き方**: `タイトル`、`H1`、`TL;DR`、`メタディスクリプション`、主要な`H2`では、患者さんが検索しそうな平易語を主軸にする
- **専門語の使い方**: SEOや正確性のために必要な専門語は、本文前半で1〜2回だけ `平易語（専門語）` または `専門語、つまり平易語` の形で橋渡しして使う
- **本文の優先順位**: 2回目以降は平易語を主役にし、業界内の言い回しはそのまま出しすぎない
- **研究紹介の言い方**: 本文では `2025年の研究では`、`複数の研究をまとめたレビューでは` のように紹介する。`Uchidaさんたちの研究` `Smithらの` のような研究者名は本文に書かず、参考文献リストにのみ載せる
- **限界をセットで書く**: 研究結果を紹介したら、同じ段落で必ず限界を添える（例：`横断研究が中心で因果関係は断定できません`、`研究の確かさは高くありません`、`人数は限られています`）。限界のない結果紹介は未完成とみなす

### ミニエピソード
各記事に匿名の相談例を1つ以上含める。使ってよいのは「よくある相談例」または「個人が特定されないよう加工した来院時の悩み」まで。改善結果、施術後の変化、ビフォーアフター、効果を示す体験談は原則入れない。

```
「運動したいけれど、動くと痛い」「整体は受けたいけれど、強い刺激は不安」。
こんな相談を、僕は日々の現場でよく受けます。先日も、長引く腰の違和感で
運動を避けてきた50代の方が、「怖くて動けないまま時間だけ過ぎた」と
お話ししてくれました。
```

### 読みやすさ（モバイルファースト）
- 段落：2〜4文で改行
- 本文の70%以上はプレーンな段落
- 箇条書きは「今日からできること」セクション中心
- 見出し：`##` と `###` を使用
- 太字：重要語の最小限強調
- 目安：約3000文字

## 記事構成（PASONA）

### 1. はじめに（Problem）
読者の悩みを代弁し、共感を示す。

**必須要素：**
- 匿名の短い相談例1つ（改善結果や施術後の変化は書かない）
- 読者への共感「〜ですよね」
- 記事で扱う内容の予告

**禁止：** 箇条書き

### 2. なぜ起こるのか（Agitation）
原因を説明し、放置リスクを淡々と伝える。

**必須要素：**
- 専門用語→直後に平易な説明
- 比喩を1つ以上
- 放置リスク（脅かさず淡々と）

**禁止：** 箇条書き、恐怖を煽る表現

### 3. 解決の方向性（Solution）
内部設計としては「評価→施術→再評価」を意識しつつ、本文では患者さんに伝わりやすい言い方で説明する。

**必須要素：**
- 評価で何を確認するか
- 施術や調整でどう進めるか
- 再評価で変化を確認すること
- 段階的に進める旨
- 本文では `今の状態を確認する → 無理のない調整を進める → 変化を確かめる` のような患者向け表現を優先する

**禁止：** 箇条書き

### 4. 今日からできること（Narrow down）
読者が自宅でできる具体策を3項目、番号付きで提示。

**必須要素：**
- 目安（回数・時間）を明記
- 「痛みが出たら中止」を記載
- 安全で再現性が高い内容

**形式：** 番号付きリスト（1. 2. 3.）

```
1. 座位の骨盤リセットと呼吸（目安2分×2回/日）
   椅子に浅く座り、坐骨で座面を感じます。骨盤を前後に小さく転がし、
   力みの少ない"ちょうど真ん中"を探してください。

2. 首のやさしいストレッチ（目安5回×2セット）
   顎を引きすぎないよう注意しながら、頭全体を後ろへスライド。
   痛みがあればそこで止めましょう。

3. 立ち上がりの分解練習（目安5回×2セット）
   椅子から立つ直前で一瞬止まり、ゆっくり立ってゆっくり座る。
```

### 5. まとめと次の一歩（Action）
要点を再掲し、前向きなメッセージで締める。

**必須要素：**
- 記事の要点をやさしく再掲
- 「できることから少しずつ」など励まし
- 相談・予約への導線（自然に）

**禁止：** 箇条書き

## 文章のリズム（緩急）

構成もコンプラも守れているのに読み進めてもらえない記事は、情報が多すぎるのではなく、文の長さ・段落の密度・段落の入り方が全部そろってしまっている。単調さを防ぐためのルール。

### 状況を書く。記事の進行を語らない

削るか残すかの判定軸は一つ。**その文が伝えているのは「体や研究の話」か、「この記事の話」か。**

- 残す：症状が出る場面、研究でわかったこと・わからないこと、僕が現場で見ている順番、患者さんの言葉
- 削る：記事の進行や性格を説明するだけの文（`ここまでは原因の話でした` `次は対策を見ていきます` `本記事では〜を扱います`）

進行の説明は要らない。次の見出しの1文目が具体で始まっていれば、読者はそのまま読み続ける。

研究の限界も「記事の使い方」ではなく「研究そのものの事実」として書く。こう直すと前置き臭が消えて、限界の記述がそのまま内容になる。

| 避ける（記事の話） | 推奨（研究の話） |
|-----------------|----------------|
| 記事内では〜という範囲で参考にします | 坂道を調べた研究ではないので、そこまでは言えません |
| ここでは詳しく触れません | 人数が限られていて、確かさは高くありません |
| この研究は参考程度に留めます | レビュー論文なので、原因を特定するものではありません |

### 文の拍

- 短い文で足場を作り、長い文で説明し、短い文で止める
- 長い説明文を3つ以上続けない。間に短い一文か、患者さんの言葉を挟む
- **医療コンテンツの制約**：`〜に違いない` と読者に思わせてから覆す書き方は使わない。体のことで誤った理解を一度持たせることになる

### 段落の密度

- 説明の詰まった段落が2〜3個続いたら、短い段落を1つ挟む
- 短い段落の役目は、わかったことの一行固定か、次に見る対象の提示に限る
- 具体（場面・数字・患者さんの言葉）に寄る段落と、意味づけで一段引く段落を交互に置く

### 見出し直後の1文目

見出し自体は目次・JSON-LDと対応しているので変えない。変えるのは**直後の1文目**。

- 避ける：`ここでは〜について説明します`（見出しの言い直し）
- 使う：患者さんが実際に抱く反問（`では、坂を避ければいいのでしょうか`）、現場で感じる違和感、その場面の具体描写

### 研究段落の単調さ

同じ形の書き出しを連続させない。`2019年の研究では` `2020年のレビューでは` `2024年の研究では` と3段落続くのは典型的な失敗。

- 研究を見つけた順ではなく、**読者の疑問が動く順**に並べ替える
- 各研究を、直前に書いた具体的な場面へ一つずつ着地させる（例：`上り坂で腰が反る、あの感じの正体がこれです`）
- 書き出しの形を変える（場面から入る／疑問から入る／まだわかっていないことから入る）

### 読み進める理由（医療向けの制約つき）

読者が最後まで読むのは、まだ答えの出ていない問いがあるから。ただし**問いの材料は、体の主張ではなく、読者の素朴な疑問と僕の思考過程から取る**。

- 使ってよい：`平地は平気なのに、なぜ坂だけつらいのか`（読者の疑問）、`僕がまず分けて見るのは〜`（思考過程）
- 使わない：効果や原因を一度断定してから覆す、不安を煽って引っ張る、問いを立てたまま答えずに終える

## 専門用語の平易化

専門用語を使ったら、**直後に**平易な説明・比喩を補う。

| 専門用語 | 平易な説明 |
|---------|----------|
| 神経筋制御 | 筋肉と神経のチームワーク |
| ウィークリンク | 動作の鎖の中の弱い環 |
| 免荷 | 体重の一部を預けて負担を軽くする工夫 |
| 不安定性 | 小さな揺れで微調整を引き出す刺激 |
| トリガーポイント | 筋肉の中の小さな結び目 |
| 筋膜癒着 | 洗濯物が絡まったようにくっつく状態 |
| 代償動作 | かばう動き |
| 可動域 | 関節が動く範囲 |
| アライメント | 骨や関節の並び・配列 |

### 検索キーワードと平易語の両立
- **読者が検索しそうな言い方を主軸にする**  
  例: `大人の側弯症`、`背骨の並び方`
- **専門語は補助的に使う**  
  例: `大人の側弯症（医学的には成人側弯症）`
- **初出で橋渡しする**
- **2回目以降は平易語を主役にする**
- **本文で研究者名は基本出さない**
- **業界語をそのまま出しすぎない**

| 固めの表現 | 推奨表現 |
|-----------|---------|
| 成人側弯症 | 大人の側弯症（医学的には成人側弯症） |
| アライメント | 背骨の並び方（アライメント） |
| 介入では | 調整を始めるときは / 対応としては |
| 個別化が重要 | その人に合わせて考えることが大切 |
| エビデンス強度にばらつきがある | 研究の確かさには差がある |
| Smithらの研究では | 2025年の研究では / 複数研究をまとめたレビューでは |

**例文：**
```
ここで鍵になるのが「神経筋制御」です。神経筋制御とは、筋肉と神経の
チームワークのこと。簡単に言うと「どの筋肉を、どの順番で、どの強さで
働かせるか」を指揮する指揮者の役割です。
```

## エビデンスと引用（自動執筆で最重要）

品質の高い最近の記事と、弱い旧記事の最大の差はここにある。

- **実在する研究だけを引用する**: 本文で触れた研究は、必ず末尾の `参考文献` に実在・有効なPubMedリンク（`https://pubmed.ncbi.nlm.nih.gov/<PMID>/`）付きで載せ、同じPMIDをJSON-LDの `citation` 配列にも入れる。
- **捏造の禁止**: PMID・雑誌名・発表年・対象人数・結果を作らない。実在を確認できない研究は引用せず、一般的な体のしくみとして書くか、`$pubmed-research` で先に調べる。
- **言い過ぎない**: 本文の主張は研究が支持する範囲を超えない。`証明された` `必ず〜する` ではなく `〜の可能性が示されました` `関連が報告されました` を使う。
- **研究の種類と限界を結果のすぐ横に**: システマティックレビュー／メタ解析／RCT／横断研究／コホートを明記する。

## 受診を優先すべき危険サイン（必須段落）

「解決の方向性」セクションに、セルフケアより先に医療機関で確認すべきケースを伝える短い段落を必ず入れる。記事の症状に合わせて次から選ぶ：安静時・夜間も強い痛み、しびれや力の入りにくさが広がる、発熱や体重減少、転倒・外傷後の痛み、症状が悪化していく。脅かさず `セルフケアより先に医療機関での確認を優先してください` と淡々と伝える。

## 執筆前のクエリ確認（テーマ決定時に必ず）

書く前に `Analytics/periodic/` の最新期の `ga4_wp_gsc_analysis_queries.csv` を確認し、次の2点を決めてから書き始める。

1. **主クエリを1つ決める**: この記事が拾いに行く検索語を1つに絞る（例：`側弯症 手術後 できないこと`）。実際のクエリデータにある語形、またはその自然な変形を使う。
2. **既存記事との重複を確認する**: 同じ主クエリを狙う既存記事があれば、新記事は書かずに既存記事への加筆・改題を検討する。1つのクエリに複数記事を積むと、順位を分け合ってどれも上がらない。

テーマ候補のストックは `HPブログ記事/ネタ帳_検索クエリ由来.md` にある。

### 実測で分かっている検索行動（2026年7月のGSCデータより）

- 検索されるのは「部位＋症状の直接語」（`背中 片側 盛り上がる` `側弯症 股関節の痛み`）と「不安・決断の語」（`手術後 痛み いつまで` `後遺症` `できないこと` `装具 種類`）
- 「大人の側弯症」のような説明的カテゴリ語を含むクエリは観測ゼロ。生活場面語（`坂道` `洗濯` `車の乗り降り`）も観測ゼロ
- タイトルが検索語そのものだった記事だけが、表示とクリックを獲得している

## タイトルとTL;DRと切り分けの型

- **タイトルの主軸は、読者が実際に入力する語**: 主クエリの語をタイトル先頭に置く。型: `〈主クエリの語〉のはなぜ？〈体のしくみ〉をやさしく解説`
- **生活場面語はタイトルに入れない**: 「どの瞬間で痛いか」（坂道・立ち上がり・洗濯など）は本文とH2で使う武器。タイトルには検索実績のある症状語だけを載せる
- **カテゴリ語を主軸にしない**: `大人の側弯症` `成人側弯症` をタイトル先頭に置かない。使う場合はタイトル後半の補足位置に
- **TL;DR**: 80〜120字・1文で、具体的な研究の数字を1つ入れる（例：`2020年の21研究メタ解析では…`）。
- **「どの瞬間で痛いか」で切り分ける**: 解決の方向性は、症状を場面・タイミングで分けることから始める（例：座っている間か、離殿の瞬間か、立ち切った後か）。負担が集まる場所を読者が特定できる、勝ちパターン記事の定石。
- **匿名エピソードの一線**: エピソードには `これは施術後の変化ではなく、来院時によくある悩みとして紹介しています` の一文を添え、ビフォーアフター体験談に読めないようにする。

## 安全・コンプライアンス

### 必須ディスクレーマー（記事末尾）
```
本記事は一般情報であり、個別の診断・治療を提供するものではありません。
痛みや違和感が出たら中止し、必要に応じて専門家へご相談ください。
```

### 禁止表現
- 誇大表現：「完治」「100%」「即効性」「必ず治る」
- 断定的な効果保証
- 他者・他院の誹謗
- 数値の断定（「約」「目安」を添える）

### セルフケア記載時の注意
- 「痛みが出たら中止」を必ず明記
- 禁忌がある場合は注意喚起
- 無理をさせない表現を心がける

## 品質チェックリスト

記事完成時に確認：

- [ ] 主クエリを1つ決めてあり、Analyticsのクエリデータ（または実在する検索語形）に基づいている
- [ ] タイトル先頭が主クエリの語で、生活場面語・カテゴリ語が主軸になっていない
- [ ] 同じ主クエリを狙う既存記事がないことを確認した
- [ ] 一人称が「僕」で統一
- [ ] です・ます調で語尾に揺れがない
- [ ] 専門用語→直後に平易説明がある
- [ ] タイトル・H1・TL;DR・主要H2で平易な検索語を優先している
- [ ] 専門語は本文前半で1〜2回の橋渡しに留めている
- [ ] `介入` などの業界語を患者向けの言い方に直している
- [ ] 本文中の研究紹介が `〇〇年の研究では` ベースで、研究者名を本文に書いていない
- [ ] 引用した研究すべてに限界（横断研究・確かさ・人数など）を添えている
- [ ] 研究の限界が「記事の使い方」ではなく「研究の事実」として書かれている
- [ ] 記事の進行を説明するだけの文がない（`次は〜を見ていきます` 等）
- [ ] 研究段落の書き出しが `〇〇年の〜では` で3つ以上連続していない
- [ ] 長い説明文が3つ以上続く箇所に、短い文か患者さんの言葉が挟まっている
- [ ] 本文の研究はすべて参考文献に実在PubMedリンク付きで載り、JSON-LD citationと一致している（捏造PMIDなし）
- [ ] 受診を優先すべき危険サインの段落がある
- [ ] TL;DRに具体的な研究の数字が1つ入っている
- [ ] 匿名エピソードに「来院時の悩み（施術後の変化ではない）」の明示がある
- [ ] 匿名の患者エピソードが1つ以上ある
- [ ] PASONA構成（はじめに→なぜ→解決→今日から→まとめ）
- [ ] 「今日からできること」が3項目ある
- [ ] 「痛みが出たら中止」が記載されている
- [ ] 誇大表現がない
- [ ] ディスクレーマーがある
- [ ] 約3000文字

### リズム点検（草稿完成後に1回）

チェックリストとは別に、推敲時に次の順で機械的に見る。

1. 段落の頭の文だけを拾って読む。「この記事の話」をしている文は削り、前後をつなぐ。削ると論理が飛ぶ場合は、その文が指していた内容を体や研究の話として書き直す
2. `〇〇年の` で始まる段落が連続していないか確認し、連続していれば場面・疑問・未解明から入る形に変える
3. 長い断定文が3つ以上続く箇所に、短い足場か患者さんの言葉を挟む
