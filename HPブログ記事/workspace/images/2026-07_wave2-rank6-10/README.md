## 作業方針

### 画像の種類

- **featured（アイキャッチ）:** 全5記事で共通アイキャッチ（media 314）から記事別画像へ差し替え
- **body（本文）:** 各記事の H2 見出し直後に挿入。既存の有用な写真・図解は残し、不足分をフラットイラストで補う（合計3枚を目標）

### 第1波スクリプトの流用

第1波フォルダ `../2026-07_top5-refresh/` の構成・手順をそのまま踏襲する。

```
2026-07_wave2-rank6-10/
├── README.md              # 本ファイル
├── image_manifest.json    # 記事別 featured / body 定義（prompt, alt, insert_after_heading）
├── wp_image_refresh.py    # 第1波をコピーし POST_IDS を差し替え
├── source/                # 生成元 PNG
├── final/                 # WebP 変換後
├── wp_preview/            # plan フェーズの HTML プレビュー
├── wp_backup/             # 更新前バックアップ JSON
├── wp_rollout_plan.json   # plan 出力
└── wp_rollout_state.json  # apply / verify 状態
```

**手順（第1波と同じ 3 フェーズ）**

1. `image_manifest.json` を作成（`common_style` は第1波と同一トーンを維持）
2. 画像を `source/` → `final/`（WebP）へ配置
3. `python3 wp_image_refresh.py plan` — バックアップ取得・HTML プレビュー生成
4. プレビューで alt・表示サイズ・デザイン統一を確認
5. `python3 wp_image_refresh.py apply` — 1記事ずつ featured + 本文を更新
6. `python3 wp_image_refresh.py verify` — WordPress / 公開ページの整合確認
